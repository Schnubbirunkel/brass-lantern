Bug-fix release: **stories can be played on Windows again.**

### Fixed
- **Windows: no story could be started** – in any format and with both Glulx interpreters. The interpreters run as WebAssembly and treat paths the Unix way, so a Windows path like `C:\Games\advent.z5` was taken as relative and the story file was never found. Paths are now translated when they are handed to the interpreter. Saving and restoring on Windows were affected the same way and work now too.
- If an interpreter stops before showing any text, Brass Lantern now says that the story could not be started (and shows the interpreter's message if there is one) instead of leaving an empty window.
