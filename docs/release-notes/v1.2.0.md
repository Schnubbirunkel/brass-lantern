First public release of **Brass Lantern** – an interactive fiction interpreter with automap, IFDB library and retro styles.

### Downloads
| System | File |
|---|---|
| Windows (installer) | `BrassLantern-Setup-1.2.0.exe` |
| Windows (portable) | `BrassLantern-1.2.0-win-x64-portable.zip` |
| macOS Apple Silicon | `BrassLantern-1.2.0-mac-arm64.zip` |
| macOS Intel | `BrassLantern-1.2.0-mac-intel.zip` |
| Linux | `BrassLantern-1.2.0-linux-x64.AppImage` or `brass-lantern_1.2.0_amd64.deb` |

The builds are not notarised/code-signed with a developer certificate.
- **Windows:** SmartScreen may warn – “More info” → “Run anyway”.
- **macOS:** after unzipping, move the app to Applications and run once: `xattr -cr "/Applications/Brass Lantern.app"`

### Highlights
- Z-code, Glulx, TADS 2/3, Hugo and ADRIFT 4 (also in Blorb files)
- Automatic map that belongs to your saved game; room notes, route walking, SVG export
- Library from your game folders with cover art, descriptions and ratings from IFDB
- 14 styles: Lectrote, Gargoyle, Parchmap, MS-DOS, Classic Mac, Mac OS 9, green/amber phosphor, parchment
- English and German interface
